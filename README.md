# Validation-Check-
This is an interactive Employee Registration form template featuring dynamic input fields and real-time state management. It includes standard registration fields, a dynamic section to add or remove specific skills, and a live "Form Preview" that displays the user's input as a formatted JSON object.

## Overview
This project is a modern, interactive Employee Registration form designed to capture user data efficiently[cite: 4]. It demonstrates dynamic DOM manipulation and real-time state tracking by updating a live JSON preview of the form data as the user types[cite: 4]. 

## Key Features
* **Comprehensive Input Fields:** Captures essential data including Full Name, Email Address, Phone Number, Password, and Confirm Password[cite: 4].
* **Dropdown Selection:** Includes a select menu for choosing the employee's Department[cite: 4].
* **Dynamic Skills Section:** Allows users to dynamically add new skill input fields using the "+ Add Skill" button, or remove them as needed[cite: 4].
* **Terms Validation:** Includes an "I accept the Terms & Conditions" checkbox[cite: 4].
* **Live JSON Preview:** Features a "Form Preview" section at the bottom that displays a real-time JSON representation of the form's current state (tracking fields like `fullName`, `email`, `phone`, `skills`, and `terms` boolean)[cite: 4].

## Technologies Used
* HTML5
* CSS3
* JavaScript (Angular for state management)
